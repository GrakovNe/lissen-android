## 1. Термины

- **Айтем** — книга или подкаст, открытый в плеере (`itemId` — id библиотечного айтема ABS).
- **Глава** — для книги глава, для подкаста выпуск. В UI слово «Оглавление» используется для обоих типов; в пунктах меню — «глава» для книг, «выпуск» для подкастов.
- **ABS** — Audiobookshelf-сервер.
- **Ряд плиток** — нижняя панель экрана плеера из четырёх кнопок с иконкой и подписью.
- **Шит** — `ModalBottomSheet`.

---

## 2. Текущее состояние (что есть сейчас)

- Экран плеера (портрет): топбар `← «Сейчас играет» [Cast] [Bookmark] [Info]`; большая квадратная обложка; название; «Глава N из M»; слайдер с таймингами `00:00:00 … 00:16:31`; транспорт (в начало главы, −10с, play/pause, +10с, в конец главы); оранжевый заголовок секции «Оглавление»; список глав (несколько видимых строк: слева номер/название, справа длительность, текущая — жирным с иконкой ноты); ряд плиток `Главы · Загрузки · Скорость · Таймер`.
- Плитка «Главы» открывает отдельный экран «Оглавление»: топбар `← «Оглавление» [Search]`, полный список глав, тот же ряд плиток с подсвеченной «Главы». Поиск на нём — полноэкранный: поле ввода вместо топбара, список фильтруется.
- Альбомная верстка: слева блок плеера **без обложки** (название, глава, слайдер, транспорт), справа заголовок «Оглавление» и список, снизу ряд плиток, в топбаре `← «Сейчас играет» [Search] [Cast] [Bookmark] [Info]`.
- Шит настроек библиотеки (`LibrarySettingsSheet` или аналог): drag handle; строки с leading-иконкой; переключатели («Только загруженные», «Скрывать прослушанные»); разделитель; раскрываемые секции («Группировка», «Сортировка») — строка с иконкой, названием, текущим значением серым справа и шевроном ↑/↓; под ней пункты с отступом и leading-иконками, выбранный отмечен галочкой (группировка) или стрелкой направления ↑/↓ (сортировка); разделитель; строка «Настройки приложения ›».
- Порядок глав задаётся один раз при конвертации ответа ABS в модель плеера и дальше не меняется.
- Иконка Cast в топбаре есть в коде, но фича не в проде.

## 3. Что должно получиться (обзор)

1. Ряд плиток становится `Загрузки · Скорость · Таймер · Настройки` — одинаковый для книг и подкастов, всегда четыре, ничего не скрывается и не дизейблится.
2. Оглавление разворачивается **на месте**, на экране плеера, тапом по заголовку «Оглавление ▾». В развёрнутом состоянии исчезает только обложка, всё остальное остаётся на своих местах. Отдельный экран «Оглавление» удаляется.
3. Поиск по главам — третье состояние того же экрана: поле ввода встаёт на место заголовка топбара, контролы плеера остаются.
4. Плитка «Настройки» открывает шит в структуре шита библиотеки: для подкаста — раскрываемая секция «Сортировка» + разделитель + действия; для книги — только действия («Отметить прослушанной», «Сбросить прогресс»).
5. Сортировка выпусков хранится локально для каждого подкаста и применяется при сборке плейлиста; смена не прерывает воспроизведение.
6. Иконка Cast убирается из топбара плеера (обе ориентации).

## 4. Экран плеера — три состояния

Экран плеера — один композабл с состоянием `tocState: enum { Collapsed, Expanded, Search }` в его ViewModel. Все три состояния — один и тот же вертикальный `Column`, отличаются только перечисленным ниже. Переходы — анимация одного экрана (`AnimatedVisibility`/`animateContentSize` на обложке), **не навигация**.

### 4.1 Общий каркас (все состояния)

Сверху вниз:

1. **Топбар** (`TopAppBar`, высота 64dp): слева `IconButton` `Icons.AutoMirrored.Filled.ArrowBack`; заголовок `«Сейчас играет»` (`titleLarge`); правые действия — зависят от состояния (см. ниже). **Cast не показывать.**
2. **Обложка** — квадрат на всю ширину минус горизонтальные отступы 24dp, скругление 16dp. Видна только в `Collapsed`. В `Expanded`/`Search` её высота анимируется до 0 (`AnimatedVisibility(visible = tocState == Collapsed)` с `expandVertically/shrinkVertically`).
3. **Название айтема** — `titleLarge`, по центру, одна строка, ellipsis.
4. **«Глава N из M»** — `bodyMedium`, `onSurfaceVariant`, по центру. N и M считаются по **отсортированному** списку.
5. **Слайдер** прогресса главы с таймингами под ним (`00:00:00` слева, длительность главы справа, `labelSmall`, `onSurfaceVariant`).
6. **Транспорт** — пять кнопок в ряд, центральная play/pause — круглая 72dp в `primary`.
7. **Заголовок секции оглавления** — строка высотой 48dp, горизонтальный отступ 24dp: текст `«Оглавление»` (`titleMedium`, цвет `primary`) и сразу после него, через 8dp, иконка `Icons.Filled.ArrowDropDown` (в `Collapsed`) или `Icons.Filled.ArrowDropUp` (в `Expanded`/`Search`) в том же цвете. Вся строка — одна кликабельная зона (`Modifier.clickable` на `Row`, `role = Role.Button`, contentDescription «Развернуть оглавление»/«Свернуть оглавление»). Справа от заголовка **ничего нет**.
8. **Список глав** — `LazyColumn`, занимает всё оставшееся место (`Modifier.weight(1f)`). Строка главы — тот же композабл, что сейчас используется в оглавлении: слева название (для текущей — иконка ноты `Icons.Filled.MusicNote` 16dp перед текстом и жирный шрифт), справа длительность; между строками `HorizontalDivider`. Тап по строке — перейти к главе (всегда, в любом состоянии).
9. **Ряд плиток** — четыре кнопки одинаковой ширины: иконка 24dp над подписью `labelSmall`:
   - `Загрузки` — `Icons.Outlined.CloudDownload` (как сейчас)
   - `Скорость` — как сейчас
   - `Таймер` — как сейчас
   - `Настройки` — `Icons.Outlined.Settings`
   Плитка «Главы» удаляется. Подсветка активной плитки (сейчас маркирует режим «Главы») удаляется.

### 4.2 Состояние `Collapsed` (по умолчанию)

- Топбар справа: `Icons.Outlined.BookmarkBorder`, `Icons.Outlined.Info` (как сейчас).
- Обложка видна.
- Заголовок секции: `Оглавление ▾`.
- Список показывает столько строк, сколько влезает; прокрутка списка допускается, но при входе в состояние список прокручен так, чтобы текущая глава была видна (как сейчас).

### 4.3 Состояние `Expanded`

- Вход: тап по заголовку `Оглавление ▾`.
- Топбар справа: **только** `Icons.Outlined.Search`. `Bookmark` и `Info` в этом состоянии не показываются.
- Обложка скрыта (высота 0). Всё остальное — на тех же местах и тех же размеров.
- Заголовок секции: `Оглавление ▴`.
- Список получает освободившуюся высоту; при входе в состояние — `animateScrollToItem` к текущей главе.
- Выход в `Collapsed`: тап по заголовку `Оглавление ▴` **или** системный «назад» (`BackHandler(enabled = tocState != Collapsed)`).
- Кнопка `←` в топбаре в этом состоянии делает то же, что и в `Collapsed` (уходит с экрана плеера) — её поведение не меняется.

### 4.4 Состояние `Search`

- Вход: тап по `Search` в топбаре состояния `Expanded`. Из `Collapsed` войти нельзя.
- Топбар: `←` на месте; вместо текста заголовка — поле ввода (`TextField`/`BasicTextField` в контейнере `surfaceContainerHigh`, скругление 24dp, высота 48dp, без обводки, placeholder «Поиск по главам», справа внутри поля `IconButton` `Icons.Filled.Close`). Правых действий в топбаре нет. Фокус и клавиатура — сразу при входе.
- Всё остальное — как в `Expanded` (обложки нет, контролы на месте, заголовок `Оглавление ▴`).
- Список фильтруется по подстроке названия главы без учёта регистра; пустой запрос — полный список.
- `Close` в поле очищает текст, **не закрывает** поиск.
- Выход в `Expanded`: `←` в топбаре, системный «назад» или тап по главе (глава при этом запускается).
- Порядок системного «назад»: `Search → Expanded → Collapsed → выход с экрана`.

### 4.5 Альбомная ориентация

- Обложка и так скрыта; заголовок «Оглавление» **без** треугольника, состояний `Expanded`/`Collapsed` нет.
- Топбар: `← «Сейчас играет» [Search] [Bookmark] [Info]` (Cast убрать).
- Поиск — существующее поведение альбомной верстки, поле поиска — там же, где оно там сейчас.
- Ряд плиток — тот же новый (`Загрузки · Скорость · Таймер · Настройки`).

### 4.6 Удаление экрана «Оглавление»

- Роут/`Composable` отдельного экрана оглавления удалить вместе с навигацией на него. Всё, что на него ссылалось (плитка «Главы», deep-link'и, Android Auto — проверить), перевести на `tocState = Expanded` экрана плеера.

## 5. Шит «Настройки» (плитка `Настройки`)

`ModalBottomSheet`, `skipPartiallyExpanded = true`. Внутри — `Column` из строк, тех же композаблов, что в шите настроек библиотеки. **Заголовка у шита нет** (как у библиотечного). Drag handle — стандартный.

Строка (общая спецификация): высота 56dp, горизонтальный отступ 24dp, leading-иконка 24dp в `onSurfaceVariant`, через 16dp текст `bodyLarge`; при наличии — значение справа (`bodyMedium`, `onSurfaceVariant`, одна строка, ellipsis) и trailing-иконка 24dp. Пункты внутри секции — с дополнительным левым отступом 16dp.

### 5.1 Содержимое для подкаста (сверху вниз)

1. **Секция «Сортировка»** — раскрываемая, при открытии шита **схлопнута**.
   - Строка-заголовок: иконка `Icons.AutoMirrored.Outlined.Sort`; текст «Сортировка»; справа короткое имя текущего ключа (таблица ниже); trailing `Icons.Filled.KeyboardArrowDown` (схлопнуто) / `KeyboardArrowUp` (раскрыто). Тап — переключить раскрытие (анимация `AnimatedVisibility`).
   - Пункты (когда раскрыто), в этом порядке:

     | Ключ | Текст пункта | Короткое имя | Иконка | Направление по умолчанию |
     |---|---|---|---|---|
     | `PUBLISHED_AT` | По дате выхода | Дата выхода | `Icons.Outlined.CalendarToday` | убывание (новые сначала) |
     | `TITLE` | По названию | Название | `Icons.Outlined.SortByAlpha` | возрастание |
     | `SEASON` | По сезону | Сезон | `Icons.Outlined.Layers` | возрастание |
     | `EPISODE` | По эпизоду | Эпизод | `Icons.Outlined.Tag` | возрастание |
     | `FILENAME` | По имени файла | Имя файла | `Icons.Outlined.Description` | возрастание |

   - Выбранный пункт: текст `onSurface`, trailing `Icons.Filled.ArrowDownward` (убывание) или `ArrowUpward` (возрастание). Невыбранные: текст `onSurfaceVariant`, без trailing.
   - Тап по невыбранному — выбрать с направлением по умолчанию. Тап по выбранному — перевернуть направление. Изменение применяется немедленно (см. раздел 8), шит не закрывается.
2. **`HorizontalDivider`** (вертикальные отступы 8dp).
3. **«Отметить прослушанным»** — иконка `Icons.Outlined.CheckCircle`. Если айтем уже отмечен прослушанным — текст «Снять отметку», иконка `Icons.Outlined.RemoveCircleOutline`. Тап — выполнить (раздел 6.1), закрыть шит.
4. **«Сбросить прогресс»** — иконка `Icons.Outlined.Restore`; иконка и текст в `error`. Тап — закрыть шит, показать диалог (раздел 6.2).

### 5.2 Содержимое для книги

Только строки 3 и 4 из 5.1 с текстами «Отметить прослушанной» / «Снять отметку» и «Сбросить прогресс».

### 5.3 Определение типа

Тип берётся из модели айтема (подкаст ↔ книга). Секция «Сортировка» рендерится только для подкаста.

## 6. Действия над айтемом

### 6.1 Отметить прослушанным / снять отметку

- Обратимое действие: без диалога, без snackbar.
- Запрос к ABS: `PATCH /api/me/progress/{itemId}` с телом `{"isFinished": true}` (или `false` для снятия). Использовать существующий API-клиент/репозиторий прогресса.
- Локальный кэш прогресса обновить так же; оффлайн — поставить в очередь синхронизации по существующему механизму, если он есть; иначе показать существующую ошибку сети.

### 6.2 Сбросить прогресс

- Необратимое действие — `AlertDialog`:
  - заголовок: «Сбросить прогресс?»
  - текст: «Позиция и отметки прослушанных глав книги «{название}» будут удалены на сервере. Отменить это нельзя.» (для подкаста — «…выпусков подкаста «{название}»…»)
  - кнопка dismiss: «Отмена» (`TextButton`, цвет `primary`), фокус по умолчанию
  - кнопка confirm: «Сбросить» (`TextButton`, цвет `error`)
- По подтверждению: `DELETE /api/me/progress/{itemId}`; очистить локальный прогресс айтема; если айтем играет — остановить и сбросить позицию на начало первой главы (по текущей сортировке).

## 7. Модель данных и хранение

```kotlin
enum class EpisodeSortKey { PUBLISHED_AT, TITLE, SEASON, EPISODE, FILENAME }

data class EpisodeOrdering(
    val key: EpisodeSortKey = EpisodeSortKey.PUBLISHED_AT,
    val ascending: Boolean = false,
)
```

- Хранить **локально, по `itemId`**, в том же хранилище, где лежат другие per-item данные приложения (если такого нет — Room-таблица `item_preferences(item_id TEXT PK, sort_key TEXT, sort_ascending INTEGER)`). На сервер не отправлять.
- Репозиторий: `fun observeOrdering(itemId): Flow<EpisodeOrdering>`, `suspend fun setOrdering(itemId, ordering)`. Отсутствие записи = значение по умолчанию.
- Значение по умолчанию совпадает с текущим поведением приложения (проверить, что сейчас выпуски отдаются по дате выхода, новые сначала; если нет — дефолт подстроить под текущее поведение, чтобы пользователи не увидели изменения без своего действия).

## 8. Движок: применение порядка

1. Найти место, где ответ ABS конвертируется в модель плеера и где список выпусков получает свой порядок. Убрать оттуда фиксацию порядка: модель хранит выпуски в том виде, как пришли, плюс поля, нужные для сортировки: `publishedAt` (epoch ms), `title`, `season`, `episode`, `filename` (из `audioFile.metadata.filename`). Убедиться, что эти поля реально парсятся из JSON ABS (`media.episodes[*]`).
2. Ввести чистую функцию `fun List<Episode>.sortedBy(ordering: EpisodeOrdering): List<Episode>`:
   - `PUBLISHED_AT` — по `publishedAt`, null — в конец;
   - `TITLE` — `compareBy(String.CASE_INSENSITIVE_ORDER)`;
   - `SEASON`, `EPISODE` — числовое сравнение, если строка парсится в число, иначе строковое; null — в конец;
   - `FILENAME` — natural sort (числа внутри строки сравниваются как числа: `Часть 2` < `Часть 10`);
   - `ascending = false` — обратить результат;
   - стабильная сортировка.
   Покрыть unit-тестами (каждый ключ, оба направления, null-поля, natural sort).
3. Плейлист Media3 (`List<MediaItem>`) собирать из отсортированного списка. Сборка должна быть функцией от `(item, ordering)`.
4. При смене `ordering` во время воспроизведения: запомнить `currentEpisodeId` и `currentPosition`; пересобрать плейлист; `player.setMediaItems(newItems, newIndexOf(currentEpisodeId), currentPosition)`; сохранить состояние play/pause. Воспроизведение не должно прерываться заметно (без перезапуска аудиофокуса, без пропадания уведомления).
5. Проверить потребителей порядка: кнопки «предыдущий/следующий», оглавление, «Глава N из M», Android Auto, виджет, шит «Скачать» («Следующие главы», «Оставшиеся главы» — считаются по отсортированному списку). Все должны читать порядок из плейлиста/одного источника, не держать свою копию.
6. Для книг сортировка не применяется — порядок глав как есть.

## 10. Доступность

- Все кликабельные строки и плитки — минимум 48dp по высоте, `contentDescription` у иконок-кнопок.
- Заголовок оглавления — `Role.Button`, `stateDescription` «развёрнуто»/«свёрнуто».
- Выбранный пункт сортировки — `selected = true` в semantics; направление — в `stateDescription` («по убыванию»/«по возрастанию»).

## 11. Что НЕ делать

- Не добавлять пятую плитку; не скрывать и не дизейблить плитки по типу айтема.
- Не ставить иконку, chip или текущее значение сортировки справа от заголовка «Оглавление» на экране плеера.
- Не делать мини-плеер, карточки, компактную обложку в развёрнутом состоянии — обложка либо есть, либо её нет.
- Не убирать контролы плеера в развёрнутом состоянии и в поиске.
- Не добавлять заголовок «Настройки» внутрь шита.
- Не добавлять опцию «как на сервере», отдельный тумблер направления, snackbar после действий.
- Не делать per-item аудио-настройки (эквалайзер, пропуск тишины) и per-item оверрайды глобальных настроек.
- Не возвращать Cast в топбар.
- Не менять сортировку глав книг.
